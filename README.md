# Workbench Web

Cloudflare web application and canonical cloud-sync service for Workbench across web, Android, iOS, and macOS.

## Status

Project scaffold and architecture plan. AI model execution is intentionally out of scope.

- [Cloudflare project plan](CLOUDFLARE_WORKBENCH_PLAN.md)

## Intended stack

Cloudflare Pages, Workers, D1, R2, Durable Objects, Queues, TypeScript, and a browser client with offline persistence.
